# 保留名单应用选择优化

需求：显示图标，窗口和托盘应用优先，降低无意义 EXE 对选择的干扰，保持原项目样式和低占用。

- [x] 按 EXE 路径合并进程，显示友好名称、程序文件名、进程数量和窗口标题。
- [x] 有窗口应用优先，托盘匹配其次，普通后台最后；默认隐藏普通后台，提供开关及搜索。
- [x] 通过 Windows 公开辅助功能名称和托盘注册表记录尽力匹配，不读取 Explorer 私有内存、不打开托盘溢出窗口、不修改系统设置。
- [x] 使用系统图标，异步读取；无图标时回退，关闭后取消未完成工作并释放图像和句柄。
- [x] 搜索与分类切换保留选择状态，已有保留项显示勾选，仅执行追加操作。
- [x] 沿用原项目 LiteButton、LiteCheck、UIColors。没有新增包依赖或常驻任务。
- [x] 增加 7 项目录排序与匹配回归；UI 实测图标、分组、空搜索、选中保留和较小窗口。

本机只读验证识别到 28 个候选应用，其中 5 个有窗口、8 个有托盘匹配（两者可重叠）。没有执行用户进程清理；统计随当时进程状态变化。

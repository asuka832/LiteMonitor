# Game Ready 界面统一记录

用户要求：优化 UI，与原项目保持一致；使用 impeccable 技能。

依据原项目 SettingsForm、UIColors、LiteButton、LiteNavBtn、LiteSettingsGroup、LiteSettingsItem、LiteCheck、LiteHintRow 的现有实现，进行局部界面统一，不更换技术栈。

已完成：

- 用与设置页一致的浅灰侧栏替换原生页签，统一白色设置分组、字体、边框与间距。
- 首页展示已扫描游戏及清理设置，程序路径等低频选项默认收起；完整配置仍可编辑。
- 底部只保留保存、恢复、预览、启动四项操作，蓝色标明主操作。扫描放在游戏列表旁，记录和放弃恢复放在恢复页面。
- 日志默认收起，保留一行当前状态；运行中提供取消，完成后隐藏取消按钮。
- 补齐游戏空列表与恢复空记录提示、游戏名称省略、可展开高级配置的滚动。
- 复用原项目控件与颜色。未增加包依赖、动画或计时器；分离布局与业务文件，未调整进程清理和扫描算法。

验证：

- 正常桌面窗口、较小窗口、四个页面、高级配置和空列表的两轮批量渲染检查。
- UI 测试只读扫描现有游戏，不启动游戏或关闭用户应用。
- impeccable 机械检测输出为空。对 C# 原生界面仍以实际渲染和源项目控件对照为主要证据。

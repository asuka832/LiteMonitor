## 小巧与低占用

使用相同 .NET 8 SDK 编译上游基线及修改版，主程序集从 779,776 字节增加至 882,176 字节，增加 102,400 字节（100 KiB）。这是未压缩程序集的体积差值，不是进程运行内存差值。

没有新增 NuGet 包。使用原生 Windows API 和项目已有 Windows Forms；没有常驻清理线程、全局扫描定时器或 WMI 依赖。进入功能窗口前，不读取 Game Ready 配置或枚举进程。

等待游戏启动期间仅按配置的游戏名称读取目标进程，且有超时；运行后使用单个进程退出事件，不轮询。关闭界面后退出事件不会保留整套表单对象，游戏结束时释放进程句柄。

便携包采用依赖现有 .NET 8 Windows Desktop Runtime 的单文件发布，保留上游资源与辅助库，不为 Game Ready 加入运行时。

## 构建基线修复

上游工程引用 `使用说明(必读).txt`，但仓库没有该文件，原始完整构建因此出现 MSB3030。仅将该内容复制项改为文件存在时才执行，没有补造说明文件或更改运行行为。

验证环境使用独立安装的 .NET 8 SDK，并通过显式 NuGet 源恢复原有依赖，未修改系统 PATH 或仓库依赖版本。其他环境可直接使用系统中的 dotnet 命令。
